# MQ Booster Agent

A simplified strategy framework for the Booster Champion 3v3 soccer tournament agent.

This framework has been greatly simplified to make it easier for players to implement, but it still needs optimization to achieve the best results. Players should try it out thoroughly in a simulation environment and only use it in the competition after successful debugging.

Start with the [Getting Started](01-getting-started.md) guide to set up Booster Studio and the agent code.
