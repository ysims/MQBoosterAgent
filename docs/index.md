# Macquarie Booster Agent

The Macquarie Booster Agent is a Python software agent for simulated humanoid robot soccer in [Booster Studio](https://github.com/ysims/MQAgent), a simulation environment developed by [Booster Robotics](https://www.boosterobotics.com/). Booster Studio is used to develop and evaluate software for Booster Robotics' humanoid robots, including in the Booster Champions competition. The competition focuses on strategy and planning for humanoid robot soccer, following rules similar to those used in RoboCup.

This repository provides a starting point for learning about and experimenting with humanoid robot soccer. The agent implements an imperfect solution for simulated 3v3 matches, with subsystems covering areas such as computer vision, odometry filtering, localisation, robot motion, strategy, and planning. The code is intended to be explored and modified, providing opportunities to experiment with different algorithms, behaviours, and approaches to robot soccer.
